# Changes since v0.8.20

## v0.8.21-alpha — Development Version 430

This release updates Flux Motion, the OBS plugin, the shared runtime and the
Suite Installer. Flux Encoder remains at v0.8.18-alpha.

### OBS compatibility and installation

- Restored plugin loading on OBS Studio 33.0.1 by replacing removed image-file APIs with Qt image decoding and stable OBS texture uploads.
- Updated Windows packaging to place the plugin and runtime DLLs beside the data folder for the OBS 33 plugin manager.
- Updated installer detection to recognize previous Flux Motion and Broadcast Graphics Live plugin layouts.
- Added build support for version labels with or without a dot after the v prefix.

### Cue automation and scene transitions

- Added source-local Cue and Uncue buttons, displayed side by side in source properties, for direct control and Advanced Scene Switcher automation.
- Added public OBS procedures for cueing, uncueing and querying cue state, including pending edits. Added integration documentation.
- Added an optional Uncue before scene transition setting for each source and a persistent global master switch. Both must be enabled; both default to disabled.
- Automatic transitions wait for participating titles to finish their outros, keeping outgoing video and audio live before resuming the original transition and duration.
- Supported groups, nested scenes, titles shared with the destination and newly assigned private output transitions. Manual T-bar operation remains under operator control.
- Added timeout recovery, immediate continuation when the master switch is disabled and cleanup when scene collections change. Repeated Uncue commands do not restart or skip an outro.

### Live graphics and text editing

- Held the current Program artwork during authoring edits until the next cue, including through the outgoing uncue and outro.
- Added alternating red/yellow pending-change indicators and a constant Pending label in the collapsed Titles and Graphics rail, with a fallback for older locale files.
- Restricted pending indicators to edits affecting the live cue. Changes to other rows or uncued content do not mark the current cue as pending.
- Preserved cue and playlist transport state when reloading the same title library and retained unchanged scene-mask media references during title edits.
- Fixed double-click word editing in Live Text Cue fields so typing immediately replaces the selected word while retaining hotkey and read-only protections.

### Scene Masks and workspace

- Added persistent collapse carets for Preview/Monitor sections and individual scene-mask cards, matching the Titles and Graphics controls.
- Restored the Titles and Graphics collapsed state across OBS sessions and added a synchronized Settings-menu toggle.
- Improved dock-layout persistence for floating positions, sizes, tabbing and split arrangements; prevented startup and teardown from overwriting saved layouts.
- Made off-air scene masks display their configured pause/cue-end frame and start animation on Program activation. Preview mirrors Program when both display the same source.

### Rendering and performance

- Shared each source's completed frame and GPU session across Preview, Program and projectors. Duplicated sources retain independent sessions; view-specific backdrop compositing and live inputs remain active on held graphics.
- Kept scene-mask mattes resident together and checked fallback paths before unnecessary scene capture.
- Preserved GPU presentations and cache identities while adjusting scene-mask position and zoom.
- Cached animation analysis and retained GPU graphs across unrelated title-library changes.
- Deferred hidden-source GPU preparation until display, preventing repeated first-frame work, and reduced audio processing for silent or hidden sources.
- Skipped destination capture and compositing for hidden, out-of-range or fully transparent adjustment and blend layers, including held uncued frames.

### Validation support

- Added regression coverage for cue transitions, shared-frame rendering, scene-mask controls, source-property buttons, live-text editing, title snapshots and version parsing.
- Added an OBS plugin-load smoke-test tool.
