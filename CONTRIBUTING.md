# Contributing

Create focused branches and keep changes scoped to one component where
possible. Run that component's tests before opening a pull request. Changes to
shared code should also validate every consuming application and plugin.

New applications belong under `apps/`; host integrations belong under
`plugins/<host>/`; reusable code belongs under `packages/`.

Contributions must be compatible with GPL-3.0-or-later and must preserve all
applicable third-party notices.
