# UI and branding icons

Most monochrome UI SVGs in this directory use `currentColor` and are rendered through the plugin icon helper so they inherit the active OBS palette. The corresponding Font Awesome Free artwork is licensed under CC BY 4.0; see the project license notice for third-party terms.

Branding assets are intentionally not recolored:

- `flux-motion-about.svg` — supplied Flux Motion About artwork, used byte-for-byte on disk. Only its version text is replaced in memory from the build version.
- `flux-motion-icon.svg` — supplied application/window icon used by the editor and plugin-owned dialogs. The artwork is used as-is.
- `../fonts/Satoshi-Medium.otf` — bundled font used by the dynamic version text in the About artwork.
